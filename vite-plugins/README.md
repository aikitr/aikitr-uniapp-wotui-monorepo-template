# aikitr 原生插件资源复制插件

`copy-native-resources.ts` 是一个专为基于 unibest 框架的 UniApp 项目设计的 Vite 插件，用于解决使用原生插件时打包后出现"插件找不到"的问题。该插件会在构建过程中自动将本地原生插件资源复制到正确的目标目录。

## 问题背景

A: 目前使用 unibest 框架在打包时可能不会自动复制原生插件资源，导致运行时出现"插件找不到"的错误。此插件确保原生插件资源被正确复制到构建目录。

## 使用说明

1. 在 `vite.config.ts` 中引入并使用此插件
2. 配置 `nativePlugins` 目录路径
3. 插件会自动将资源复制到对应的平台构建目录
